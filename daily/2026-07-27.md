## ViewComfy Startup Method (Working)
The only reliable way to launch detached processes via SSH on Windows:
```
wmic process call create "cmd /c cd /d C:\Users\User\Desktop\ViewComfy && npx next dev > C:\Users\User\Desktop\vc_final.log 2>&1"
```
- Survives SSH disconnection
- Scheduled tasks (`schtasks /run`) did NOT work from SSH
- `start /B cmd /C` did NOT create a viable background process
- VBS `WScript.Shell.Run` did NOT work from SSH
