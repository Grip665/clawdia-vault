## 🔧 In-Service Manual table bug (12:35-12:40 EDT) — FIXED
Larry reported: "10 on page 3 looks way different than the others and so does revision history at the end."
Root cause in `~/Desktop/PHC-InService-2026/build_manual.py` `add_md()`:
- Detector was `set(lines[i+1].strip()) <= set("|-: ")` — an EMPTY line passes this test
  (empty set ⊆ anything), so the LAST row of every table was read as a table header.
- Effect: last row = its own 1-row bordered table; all sibling rows fell through to
  `doc.add_paragraph` and printed as raw `| a | b |` text.
- Hit 3 tables: Section 1 topic catalog (only row 10 was a table), Section 4 compliance
  summary (only "Records on file"), Revision history (only row 2.0).
- Roster table happened to work because its separator `| | | | | | | |` IS a valid subset.

Fixes applied:
1. New `_is_sep()` helper: starts with `|` AND contains `-` AND charset ⊆ `|-: `.
2. Added real `| --- |` separator lines after all 4 table headers in MD.
3. Added `WIDTHS` dict → per-table column widths (both `t.columns[j].width` AND `cell.width`;
   cell.width alone was NOT enough — LibreOffice ignored it, columns stayed equal).
4. `w:tblHeader` on row 0 so headers repeat across page breaks.
Rebuilt docx→pdf (17 pp). Verified visually: catalog = one continuous table, no pipes,
no mid-word breaks. Old files backed up `.bak-20260925`.
