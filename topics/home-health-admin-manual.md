## 0. The manual in one breath
Every day you: **(A)** triage email, **(B)** handle Phoenix notices / authorizations / terminations, **(C)** work missed visits & resolutions, **(D)** answer calls/coverage, **(E)** file + keep matrices, and on schedule **(F)** run employee checks/competency/in-service and **(G)** coordinate **payroll** (Thursday). This manual breaks each into steps.

---

## 1. Daily start — email triage (do FIRST)
1. Open **No-reply Phoenix** emails FIRST — they affect active services **today** (temp stop-start = schedule change; copy client name/#).
2. **Indeed** messages/applications → follow-ups + interview reschedules.
3. Home care updates (client not approved for something).
4. Junk (Uber, forms).
- **NEVER delete anything in the home care inbox.** Clear junk from the others.
- Company email **NOT accessible off-site** (plan to come in / find a workaround).

---

## 2. Authorizations & terminations
- 4 items for 1 client = **2 services × (cancel + restart)**.
- Auth # → **Terminations → top one → Preview → download → Cmd/Ctrl+Z → Enter**.
- **Always print on ANY change.** **Highlight** address/phone changes so they're obvious.
- Accepting an auth: check schedule → (companion ~2hr; personal care varies) → **Accept → Preview → download → print**.
- Respite this week = short change, redo next week. Forgot to print? Dashboard download arrow still has the batch (no name shown, HIPAA).

## 3. Missed visits / service interruptions / resolutions
- **Miss Visits** screen → week range (weekend = Fri→yesterday).
- Types: service interruption, declined services, **resolutions (the "2s and 5s" codes)**.
- On a "2s and 5s" notice: **acknowledge + try to resolve** → "I'll reach out to the aide and resolve it" → send → clears.
- Know each client's aide for coverage; know MAX-beneficiary clients; watch turnover on aides.

  **H. Resolution rollover rule (from 08-14 training video #3 — IMPORTANT):**
  1. Pull **Reports → Resolutions** for the 2 weeks.
  2. **Verify EVERY resolution has PAID OUT** — all accepted, each has a status ("CLTC action"/something in that column = processed). Slide over to **remove the company-name column** before printing (keep worker ID + hours visible).

  4. Next pay week: **add those hours manually** (provider activity only pulls hours worked IN that pay period — rolled-over hours were worked earlier, so they won't show) → **staple the rollover report to that week**.

### 🗓️ Client list / schedule tracker — Word table system (from 08-12 training)
A master **Word table** (alphabetical) that's your at-a-glance reference for who every client is, who works them, and whose they are. Columns: **name, address, contact person, phone, CLTC number, service type, hours, schedule, who's working it.**

**Color-code legend (crucial):**
- **Dark green** = service days on that client's schedule.
- **Light green** = **NOT** a service day.
- **Blue** = **Max's people** (covered, never worry about staffing them).
- **Yellow** = **open** — needs to be staffed / filled (designates a client you need someone for).
- **Red** = **on hold** (e.g., caregiver moved away, no active coverage).

**How to build/maintain:**
- **Insert → Table**; edit via **Table Layout → add row** (re-add a returning client; download his auth to transfer info over).
- Capture: phone number for the client, **authorized representative** (name + number + relationship, e.g. brother/sister), schedule days/hours.
- Include non-tech-savvy caregivers (e.g., a client's mom who isn't tech-savvy → you may need to go see her if she has issues).
- Cross-check who works a client via **Provider Activity report** (it shows the actual aide).
- Optional flavor: add small icons/pictures (cat/dog/smoker) for extra at-a-glance info.
- Serve purpose: pull it when you're on the go / need info without logging into Phoenix.

**This is a live, current document** — keep it updated as clients come/go (delete rows for clients no longer active, add returning ones, change colors as coverage changes).
