Participant Folder — Compliance Self-Audit Checklist

Prestigious Home Care · Personal Care / Companion · Built 08-11-2026 · Source: HCBS Provider Manual (7/1/25)
Companion differs: initial supervisor visit ≤ 90 days of start, then on-site ≥ once / 365 days (not PCS 30-day + every 4 mo). No ADLs / no skilled care. Same task-sheet rules, 2-tier complaint form, 2yr/5yr retention.

A. Mandatory Contents — every active record

A1 All service authorizations (current + prior) — no service before start date
A2 Current SCDHSS Service Plan (+ annual) — OIDD: use assessment instead
A2b Medicaid eligibility verified monthly (dated proof in file)
A2c RN/LPN pre-start home visit (EVV + documented)
A3 Right to Complain documentation
A4 Advance Directives
A5 Task sheets (see B)
A6 Supervisory visit documentation (see C)
A7 Incident reports / complaint records
A7b Backup-plan documentation + missed-service calls in file
A8 Retention: active ≥2 yrs ✓ · all ≥5 yrs ✓ · kept at contract address

B. Task Sheets — HIGH RISK

B1 No participant/responsible-party signature on any sheet
B2 Supervisor signed (original, no stamp) + dated every 2 weeks
B3 Filed in record ≤30 days of service
B4 Any resolution date has a matching task sheet in file
B5 Ordered / filed chronological (tabbed folder)
B6 Multi-service sheets: each service/task identifiable

C. Supervisory Visits

C1 Initial visit ≤30 days after service starts
C2 Then at least every 4 months per participant
C3 Aide present during ≥1 visit each 12-month period
C4 Break in service >60 days → new initial visit on resume
C5 Recorded in EVV from participant's home (SCDHHS)
C6 Filmed in record ≤30 days of visit

D. Supervisory Visit Report — must contain

D1 Services delivered match Service Plan / Authorization
D2 Participant's needs being met
D3 Any complaints lodged referenced
D4 Brief statement on changes in service needs
D5 Supervisor original signature + date (no stamp)
⚠️ NEVER: ask participant to sign a task sheet · use stamped signatures on any of these · file late. Missing task sheet on a resolution date = overpayment/denial risk.
✅ Confirm with trainer before go-live: exact Right-to-Complain / consent form names · electronic vs paper records + backup · incident report form & location · where 120-day nurse-visit papers go.
Audit regularly (weekly on a folder or two). If anything unchecked, fix BEFORE any survey/audit.
