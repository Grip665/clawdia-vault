# Prestigious Home Care — New Employee Hiring Packet Procedure
_Distilled 2026-08-11 from office training transcript (hiring packet + background checks)._
_Raw source: transcript-2026-08-11-hiring-packet-training.txt. Trainers: Christina Turner / lead._

## What the employee must bring (4 items)
1. Driver's license
2. Social Security card
3. Insurance card
4. Direct deposit info

Work can start with just license + social; insurance + direct deposit required **before payroll**.

## Standard hiring flow (after an in-person interview goes well)
1. Print copies of license + social card.
2. **OIG** (Medicaid exclusion list) — FREE. Legal first + last name as on license. Print **search + results**.
3. **Credential / CNA Registry** — FREE. Name as on license; click "I'm not a robot". Print search + results.
4. **Sex Offender registry** — FREE. First + last name. Print the results section.
5. **SLED background check** — PAID (company card). First+middle+last(+maiden), **social (required)**, DOB, sex, company email → Review → Acknowledge → Make Payment (SC eGov, credit/debit). Result PDF must show date+timestamp, full name+maiden, social, DOB — none may be missing. Auto-emailed to company email too. Print + file, plus receipt.
6. **DMV 10-year (tenure) driving record** — PAID (~$11). License #, social, DOB, address as on license. Record type = **TENURE**. Watch for *suspended* license → can still work but NOT a client whose services include transportation. Print receipt + full record.

**Free (3):** OIG, CNA registry, Sex offender.
**Paid (2):** SLED background, DMV driving record.

## Background / disqualifier policy (Medicaid/state)
- **Felony = hard no**, no exceptions (any age, any history). Confirmed non-negotiable by Medicaid.
- **Misdemeanor** = company discretion, EXCEPT violent offenses toward a person, or child/elderly neglect/abuse. Accepted statutes are in the SC provider manual.
- SLED shows charges AND convictions (not just convictions).
- Unsure → call the Medicaid provider line and ask (yes / discretion / no). Save the number.
- A felony can be worked around ONLY if the applicant brings a **certified court letter** that it was dropped.
- **Fingerprinting:** required only for **facilities** (e.g. adult day centers/daycare). **Home care is not a facility → no fingerprints.** If moved to SC <12 months ago, recommend federal fingerprinting (via IdentiGO) anyway + still needs SLED.

## Hiring packet assembly
- **Packet 1 (new employee package):** print whole thing.
- **Packet 2 (Prestigious 2):** print pages 1–19 (embedded clinic pages).
- Pull **one of each**: in-service, competency **both** (children + adult), payroll form, phone form, strike policy, W4, I-9.
- **Health assessment** = last page of packet 1 → pull out, swap in pre-stapled copy (keep drug test + health assessment + in-service pre-stapled, 3 docs together).
- Stack: packet 1 on top → packet 2 (health assessment pulled) → health docs (health assessment, drug screen, in-service) → payroll + deposit + both state forms → competency in back → phone form in back.
- Employment verifications (food stamps / disability) go in a **SEPARATE folder** from employee documents.

## Other notes
- Date + timestamp everything (before they start).
- On closing a job: **don't send automated rejection** — keep applicant lists to pull from later (e.g. re-open and hire from old candidate pool).
- Confirm interview in the briefcase; candidate lists live under jobs.
- OIG/registry runs are per legal name as on the license (proper capitalization, hyphens/dashes matter).
- Onboarding example used in training: **Jessica Berrios** (DOB 7/1/1995, m. Leanne) — hire packet live demo.
