Creating a ramp referral
Saving Ramp Request form
• When all required information has been
  entered, the case manager will have the
  options to:
   • “Save” – Allows the user to save the
     information without finalizing the ramp
     request. Users can go back and make any
     changes and finalize the ramp request later
   • “Save and Complete” – allows the ramp
     request to be completed and forwarded to the
     Ramp Provider when the ramp referral is
     created
                     OR
   •   “Save and Refer to Emod Specialist” –
       sends ramp request to the Emod Specialist to
       review. Ramp Referral can’t be created until
       the Emod Specialist approves the ramp
       request. A note is displayed when a ramp
       request must be reviewed by the Emod
       Specialist
                               Ramp Referral Process
Creating a ramp referral
Home Assessment
• Once Ramp Request information has been
  entered, click “Save and Complete”
• Completed Ramp Requests are displayed
  under the “Ramp” sub-tab
• Now, the case manager will need be able to
  create the ramp referral from the “Waiver
  Supports” tab
• When the ramp referral is created and sent
  to the Provider, the Ramp Request form is
  attached to the referral along with the
  Ramp Completion form
• Ramp Requests more than 90 days from
  the “Create At” date will not process.
  The case manager will have to create a
  new ramp request.
