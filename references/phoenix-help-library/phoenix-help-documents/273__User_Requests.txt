                User Requests
 Requesting Phoenix access is now an electronic
  process
 When a worker needs access to Phoenix, providers,
  central office, and area offices can create a User
  Request via Phoenix for their worker
 Terminating and updating Phoenix access for a worker
  will be completed via Phoenix electronic format
 Paper format of the Phoenix Access Request form will
  no longer be accepted (Exceptions: User access for
  Medicaid Eligibility workers, new CM providers, or
  state staff requesting additional area offices

           Pending User Requests
 The new request will be displayed under the “Open” request tab as
  “Pending”
     A user request will remain in “Pending” status until an action is taken by Central
      Office (Approve, Deny, or Return Request)


 Notifications will be sent to the new user only. Provider administrators and
  State staff will have to check the Open or Closed Request tabs for the status of a
  request

  processing

         Activating User Requests
•   Once the user request has been approved by Central Office, a notification will be emailed
    to the new user
•   Providers may have to use the worker’s personal email address to receive the notification,
    if the worker has not received a state email address before the request is made
•   The notification will contain the user’s Login ID
•   The user will need the activation code in order to setup their Phoenix account. New users
    will have to retrieve the activation code from their Provider administrator or State staff
       Activating User Requests
• Provider administrators and State staff will need to give the new user the
  activation code once the user receives the notification that the user id has been
  created
• The activation code will expire 24 hours after the user request is
  approved. If the user does not activate their account within 24 hours of
  receiving the activation code, then the administrator will need to request a new
  activation code
       Activating User Requests
• If the user’s activation code has expired, the Provider administrator or State
  staff will need to create a new activation code
• To request a new activation code, from the Home screen click “User Requests”
       Activating User Requests

• Provider administrator and State staff will need to provide the worker with the

                      Terminating Users
•   A Blue notification banner will be displayed when the user does not have any assigned
    cases
•   Enter “Termination Date” and “Termination Reason”. (Termination and Termination
    Reason are required fields)
•   Entering a future date in the “Termination Date” field will result in the User ID
    remaining active until that termination date
•   Click “Terminate User”
                    Terminating Users
•   A Red notification banner will be displayed when the user have assigned cases. Providers
    will need to run a roster report and have cases reassigned
•   If the user is terminated before cases are reassigned, then the provider will not be able to
    mimic the terminated user to view their caseload
•   Continue the termination process and click “Terminate User”
               Terminating Users
