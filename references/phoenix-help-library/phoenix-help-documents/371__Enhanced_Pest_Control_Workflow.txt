Treatments
 Completed bedbug treatment will be
   displayed under “Treatments” tab
 If the bedbugs were not eradicated, then
   the provider will need to complete and
   record an additional treatment(s)
 Click “Record new Treatment” and
   repeat the previous steps
 The assigned case manager will receive a
   notification when the bedbug has been
   eradicated
 The case manager will create the
   authorization and the provider can bill
   for services as normal
     The case manager can rollback the status,
      if the bedbug has not been eradicated
     Provider will need to complete additional
      treatment(s) and record each treatment
      until the bedbugs have been eradicated
