Emergency Events – The Emergency Events banner
changes from Red to Green once the provider’s status
has been updated.

If the emergency is more than one day, the provider
will need to update their status each day the
emergency event is active.

Daily changes for affected counties and/or services will
determine whether a provider will need to update their
status.

For example, An emergency event was active for
Sumter and Clarendon counties on 7/1/18. The
providers for both counties will receive the emergency
event alert. On 7/3/18, the emergency event was active
for Clarendon county only. Providers in Sumter county
will no longer see a emergency event alert; however,
providers in Clarendon county will still see the
emergency alert. Providers in Clarendon will continue
to update their status.

The emergency events banner will disappear once the
event has ended.
