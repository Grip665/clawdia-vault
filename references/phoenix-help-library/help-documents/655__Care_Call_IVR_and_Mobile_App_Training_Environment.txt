The training environment has been expanded to include scenarios for six Provider types, plus Nurse Supervisors, and IVR scenarios have been provided for both English and Spanish.  However, the same training scenarios are shared by all Providers, so it is possible occasionally on checkout that a worker will hear their own check in, plus check in(s) from other worker(s) using the system.  To make this less likely to become an issue, the environment includes two features:Multiple sets of common scenarios – There are multiple copies of frequently used scenarios – e.g. 10 copies of the In-Home Agency services scenarios.  This means that if a collision with another trainer occurs on checkout, the trainer can simply pick a different worker id to use a different set of scenarios.30 Minute training checkout window – In the training environment, the checkout process only looks back 30 minutes to find matching check ins.  This means that if a trainer checks in but does not check out, the orphan check in is ignored for training purposes after 30 minutes.Both of these features make it less likely that trainers will conflict with each other, and make it easy to adjust if they do.Mobile App users need to download and install the AuthentiCare® mobile app from the Apple® App Store or Google® Play Store and enter the setup code SCTRAINPRD to use the training environment.  The mobile device id for the device to be used for training needs to be registered on the Worker or Provider record in Phoenix at least 30 minutes before use with the Training system, during the business day.  The instructions for how to display the device id on the device are included with the Mobile App setup and user guide.  Mobile devices that have been registered in Phoenix Production are set up in the Training environment by a process that runs every 30 minutes during business hours.  (The process does not run overnight.)  When the user is finished with training and ready to use the app for normal check in and checkout, the user can go into the device Settings for the App and clear application data.  Then the user can restart the AuthentiCare® app and it will accept the setup code for production:  SCDHHSPRD.Training ScenariosThe Training Scenarios in the Training Environment are set up by provider type to mimic how workers for specific providers will use the Care Call system.  Each scenario is selected by logging into the IVR or Mobile App with a corresponding worker id attached to the scenario.  Scenarios have been set up as follows:For IVR, the trainee dials the IVR phone number and logs in with the worker id for a training scenario.For the Mobile App, the trainee starts the app by tapping the Mobile App icon.   The trainee then logs in with the worker id for a training scenario desired.  The Mobile password for all Training scenario worker ids is:  Pass22!! The first four digits of the worker id select a Training provider record – For HIPAA compliance, these Training providers are all “made up” and not real providers.  For common scenarios, like in-home agency care, the system provides up to ten providers, each with their own complete set of training scenarios.  Since these are all equivalent, users can pick any one of the providers for each type and get the same training.The last four digits of the worker id select a Training scenario for that provider -- For example, logging in with worker id 00101111 selects the first scenario in the table below for in-home agency training provider EN0010.
